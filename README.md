### 👨‍💻 Sobre Mí

Desarrollador de software con experiencia en el diseño y despliegue de **arquitecturas web full-stack**, **aplicaciones móviles multiplataforma** y **gestión de infraestructura en la nube con Docker**. 

Me enfoco en construir productos de software completos, rápidos y mantenibles, desde el modelado de datos hasta el despliegue en entornos de producción con automatización CI/CD.

- 🔭 **Proyecto principal:** [MoonPanel](https://github.com/GatitoLetalxd/MoonPanel) — Panel de control para aprovisionamiento automatizado de VPS, contenedores Docker y subdominios dinámicos.
- 📱 **Desarrollo Móvil:** Aplicaciones nativas e híbridas con React Native (Expo) y Kotlin para Android.
- 🌐 **Soluciones empresariales:** Desarrollo de plataformas para clientes reales (e-commerce y gestión automotriz).
- 🎓 **Formación:** Universidad Nacional Amazónica de Madre de Dios (UNAMAD).
